Google Search Console: automatic connection

{% set st = g.status %} {% if not g_on %}

Not connected yet. One-time setup, about 15 minutes. After that the website collects the figures itself every day.

  1. Open console.cloud.google.com with the same Google account you use for Search Console. Create a project named VALUERAQ.
  2. In the search box at the top type Google Search Console API, open it and press Enable.
  3. Open the menu → IAM & Admin → Service Accounts → Create service account. Name it valueraq-seo and press Done. No roles are needed.
  4. Tap the new account → Keys → Add key → Create new key → JSON. A file downloads. Keep it private.
  5. Copy the account's email address (it ends with gserviceaccount.com). In Search Console → Settings → Users and permissions → Add user, paste it and choose Full.
  6. In Render → valueraq → Environment → Add environment variable, name it GSC_SERVICE_ACCOUNT_JSON and paste the whole contents of the downloaded file as the value. Save. The site restarts by itself.

Never send the key file by chat, email or photo. It goes only into Render.
